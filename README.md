# 『経済セミナー』全記事データベースを提供

このリポジトリでは、[株式会社日本評論社](https://www.nippyo.co.jp/)が発行する『[経済セミナー](https://www.nippyo.co.jp/shop/magazines/latest/3.html)』の創刊号（1957年4月号）から最新号までの記事情報を収録した全記事目録をウェブ上で提供するをサイトを運営しています（随時更新）。

キーワード、著者、発行年、特集・連載などから記事を検索・閲覧できます。

本データセットを用いたさまざまなコンテンツも、今後提供していく予定です。

## ウェブサイト

**『経済セミナー』全記事データベース**

https://keisemi.github.io/keisemi-article-index/

記事目録の原データも、上記URLのウェブサイトからExcelおよびCSV形式でダウンロードできます。
